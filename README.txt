세입자 관리 V57 - 앱(PWA) 배포용

1. 이 ZIP의 파일 전체를 HTTPS 웹호스팅에 업로드하세요.
2. 휴대폰 Chrome/Edge/Safari에서 배포 주소를 엽니다.
3. Android: 브라우저 메뉴 > 앱 설치 또는 홈 화면에 추가
   iPhone: Safari 공유 > 홈 화면에 추가
4. 설치 후 일반 앱처럼 독립 화면으로 실행됩니다.
5. Google Drive 연동을 쓰려면 Google Cloud OAuth의 승인된 JavaScript 원본에 실제 HTTPS 배포 주소를 등록하세요.

주의: Google 로그인/Drive 동기화에는 인터넷 연결이 필요합니다. 기본 화면과 저장된 로컬 데이터는 PWA 캐시/브라우저 저장소를 사용합니다.
